# Ramen

Ramen garde ton ordinateur allumé pendant que Claude travaille. Ramen keeps your computer awake while Claude is working.

Téléchargement / Download : https://ramen-app.vercel.app

- Mac : `Ramen-mac.dmg`
- Windows : `Ramen-win.exe`

Les fichiers sont dans les [Releases](https://github.com/m4tbrn/ramen/releases/latest).
